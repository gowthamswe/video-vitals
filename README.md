# VideoVitals

Chrome extension that lets you flag clickbait and rate information density on YouTube videos, with community averages. Backend is Cloud Firestore — no server to host.

## Project layout

```
video-vitals/
├── manifest.json           # Extension manifest (MV3)
├── firestore.rules         # Security rules — deploy to your Firebase project
├── src/                    # Extension source
│   ├── background.js       # Service worker: orchestrates auth + Firestore
│   ├── firebase-client.js  # Firebase Auth + Firestore via REST (no SDK)
│   ├── content.js          # Injects panel on youtube.com/watch
│   ├── content.css         # Panel styling
│   ├── popup.{html,js,css} # Toolbar popup (sign-in, profile)
│   └── config.js           # Firebase project ID + Web API key
├── icons/                  # 16/48/128 PNG icons (generated)
└── scripts/
    └── generate-icons.mjs  # Regenerate icons
```

## One-time setup

### 1. Google OAuth client (already done if sign-in works)

`manifest.json` contains the **Chrome Extension** OAuth client ID, and that client's "Application ID" matches your loaded extension's ID. Sign-in via the popup confirms this is correct.

### 2. Firebase project

The extension talks directly to Firestore via REST. You need:

1. A Firebase project (we're using `video-vitals-dev`).
2. **Authentication → Sign-in method → Google → Enable.**
   - https://console.firebase.google.com/project/video-vitals-dev/authentication/providers
   - Set the project support email when prompted. Save.
3. **Firestore Database → Create database** → Start in **production mode** → pick a region.
   - https://console.firebase.google.com/project/video-vitals-dev/firestore
4. **Project Settings → General → Web API Key** (under "Your project").
   - Copy it and paste into `src/config.js` → `FIREBASE_API_KEY`.
5. Deploy the security rules. Either:
   - Paste `firestore.rules` into the Firebase Console → Firestore → Rules tab → **Publish**, OR
   - From the Firebase CLI: `firebase deploy --only firestore:rules`.

That's it. No server to run.

### 3. Reload the extension

After updating `src/config.js`, reload at `chrome://extensions`.

## Data model

Firestore path: `videoRatings/{videoId}/users/{firebaseUid}`

Document fields:
- `clickbait` (bool, optional) — true if user flagged the video
- `density` (int 1–10, optional) — user's information density rating
- `updatedAt` (timestamp) — when the rating was last changed

Community stats are computed on read by listing the `users` subcollection. Fine up to a few hundred ratings per video; swap to Firestore aggregation (`count`, `avg`) or a Cloud Function trigger if you outgrow that.

## Security rules (summary)

- **Reads:** any signed-in user.
- **Writes:** only by the user whose UID matches the doc ID, and the doc must have only the allowed fields, with `density` between 1 and 10.

Full rules in `firestore.rules`.

## Using it

1. Click the VideoVitals icon → **Sign in with Google**.
2. Open any YouTube video.
3. Panel appears below the title:
   - **🚩 Clickbait** — toggle to flag.
   - **📊 Info density** — drag the 1–10 slider.
   - Community stats refresh every 30s.

## Privacy

Stored in Firestore: your Firebase UID, your ratings, and a timestamp. Stored in extension storage: your email, display name, photo URL (for the popup), and a Firebase refresh token. No browsing history, watch data, or video metadata is collected.

## Icons

PNGs in `icons/` are generated by `node scripts/generate-icons.mjs`. Edit that script to change the design and re-run.
